# Python String Assignments

This folder contains 40 Python programs practicing Python string operations and methods.

## Topics Covered
- Uppercase and lowercase conversion
- Character counting
- Vowels and consonants
- String searching and replacement
- Splitting and joining strings
- Character extraction
- String reversal and palindromes
- Punctuation removal
- ASCII values
- Duplicate character removal
- Longest and shortest words
- Identifier validation
- Uppercase and lowercase counting

Each program is saved in a separate Python file, with the assignment question in a comment at the top.
