# Python List Practice

## About

This folder contains 40 Python programs based on lists and list operations. These programs are part of my Python learning journey as an MCA student.

## Topics Covered

* Creating and appending elements to lists
* Inserting and removing elements
* Using `pop()`, `clear()`, and `copy()`
* Counting and finding elements using `count()` and `index()`
* Sorting and reversing lists
* Extending and merging lists
* Checking list membership
* Finding maximum, minimum, sum, and average
* Taking user input to create lists
* Removing duplicate elements
* List slicing and updating elements
* Converting between lists and tuples
* Finding the second-largest distinct number
* Finding common elements between lists
* Filtering even and odd numbers
* Checking whether a list is a palindrome
* Working with nested lists
* Practising common list methods

## Language

Python

## Purpose

To practise Python list operations, strengthen programming fundamentals, and improve problem-solving skills.
